# 🛍️ Responsive E-Commerce Website

This is a **fully responsive E-Commerce Website** built using **HTML**, **CSS**, and **Bootstrap**. The website provides a clean and modern interface for online shopping with sections for products, categories, featured items, and more.

 🚀 Features

✅ Responsive design (works on desktop, tablet, and mobile)  
✅ Homepage with hero banner and product highlights . 
✅ Contact and footer sections and more..
✅ Built entirely with **HTML5**, **CSS3**, and **Bootstrap 5**


 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- FontAwesome (for icons)
